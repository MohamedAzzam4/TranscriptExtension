## Changed contracts

- Added `transcriptSource` record to experiment schema (kind, provider, language, purpose, timingProvenance, track, model, device)
- Added pure helper `selectedTranscriptSegments(experiment)` — returns `captionSegments` when source is `youtube-auto-caption`, otherwise `asrSegments`
- Backward compatibility: schema-v4 experiments without `transcriptSource` treated as `legacy-local-asr`
- Library schema v1 records now include `transcriptSource`; migration is idempotent
- YouTube platform: default "YouTube transcript first" policy — fetches eligible original automatic caption track (from yt-dlp `automatic_captions`, prefers `-orig`, matches audio language, rejects translated tracks, validates JSON3, checks timing compatibility)
- Compact advanced setting: "YouTube transcript first" / "Local audio transcription"
- Caption reuse path skips audio download and Whisper initialization
- Translation uses existing pipeline and persistent cache; no YouTube auto-translated tracks
- YouTube local-ASR timing diagnostics added (sanitized, no signed URLs/cookies/PCM)
- Saved vocabulary loaded at session start into normalized `Set`; exact whole-token matches marked in source transcript with underline style
- Immediate save/remove refresh of visible cue; accessible label includes "(saved)"
