2026-10-26. WP2.4/WP2.5; baseline d8d65cb on codex/local-media-loopback.
Plan: `docs/WORD_CARD_TABLE_UI_PLAN.md`. Uses existing plain JavaScript,
Shadow DOM and CSS, with ui-ux-pro-max hierarchy/table/accessibility guidance.

## Scope and changes

- Other meanings is now inside Meaning, below its main German definition and
  target-language explanation. Its existing visibility/expansion bindings remain.
- The card explicitly owns its font rather than inheriting caption text sizing.
  Section labels13px bold; all disclosure summaries12px with muted color,
  pointer/hover feedback and visible keyboard focus.
- Available verb summary fields render in a semantic two-column overview table.
  Detailed conjugations render in a full-width three-column table: tense/mood,
  person, form. Row groups use original section/tense/mood; every supplied form
  and alternative remains present. Detailed forms stay collapsed initially.
- Subtle green dividers, cell padding and contained horizontal overflow match
  the existing card. Tables have row/column headers and focusable scroll regions.
- Dictionary extraction, translation providers, saved records, audio/replay,
  voice behavior, source links and cue timing are not edited. Missing dictionary
  data is not invented or corrected by this presentation change.
