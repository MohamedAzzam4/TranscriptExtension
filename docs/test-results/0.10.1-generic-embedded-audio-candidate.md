## Implemented behavior

- Observes clear HTTP media requests at the extension service-worker boundary,
  including worker traffic that page fetch/XHR wrappers cannot see.
- Classifies extensionless manifests from response content type and records
  segment requests as evidence without trying to decode a segment as a full
  source.
- Reinserts the main-world observer, isolated bridge, and application scripts
  into all accessible frames whenever the user starts analysis. This covers
  tabs that remained open across an unpacked-extension reload.
- Ranks network-observed candidates together with current-source, source
  element, page fetch/XHR, performance, YouTube, and Netflix candidates.
- Sends candidate-specific safe replay headers to the local decoder.
- Drops Cookie, Authorization, and every non-allowlisted header immediately.
- Shows observer versions/readiness, reusable candidate count, segment evidence,
  and safe header names in the extension diagnostics.

## Known limitations

- `webRequest` exposes request metadata, not response bodies.
- This version does not replay cookies, authorization, DRM material, CAPTCHA,
  or anti-bot state.
- A page must produce fresh network traffic after the updated extension is
  loaded; an already buffered title may need a page reload.
- Worker traffic without a useful initiator can be ranked with other tab media,
  so the selected language and audible source still require manual confirmation.
- A real AnimeKai/AniWorld Level 2 PCM result is not yet available; therefore
  WP4.1 has not passed.
