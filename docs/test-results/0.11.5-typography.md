## Changes

Open Sans replaces the mixed serif/monospace/system UI treatment. One locally
bundled variable font covers headings/body/controls, with Tahoma/Arial/system
glyph fallbacks. Five shared sizes12/14/16/18/22px are defined in typography.js,
loaded before popup/setup styles and injected before content.js. Page/card
headings use22px; saved words18px; Home and Videos video titles16px; primary
body/definition/example/control text14px; help/metadata/disclosures12px.
Word-card section labels remain bold14px above12px disclosure labels, preserving
the user's requested hierarchy. Diagnostics prose uses the UI family. History
titles wrap fully, retaining access to long names and existing video actions.

Only the named font face is registered on host documents. No root UI tokens or
site selectors are injected there; those stay inside our Shadow DOM. Extension
pages get the same shared tokens. Reinjection deduplicates font registration.
Only the bundled font is web-accessible; no Google Fonts request occurs during
use. Caption font/size choices, defaults, translation and saved data are unchanged.
