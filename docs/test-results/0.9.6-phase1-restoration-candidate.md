## Candidate changes

- Added deterministic rules distinguishing suppressed clicks, active text
  selection, ordinary word lookup, and non-word clicks.
- Selection detection now checks both ShadowRoot and Window selection APIs and
  tolerates a browser implementation rejecting either call.
- Caption pointer, double-click, copy, and click events are stopped from leaking
  into the underlying player without preventing native selection/copy.
- Word-card content is explicitly selectable.
- Word-card section headings are now concise English labels.
- Added a protected feature registry, a one-click regression runner, and a
  manual interaction checklist.
