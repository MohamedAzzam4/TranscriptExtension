## Real-browser evidence received

- The user reported that AniWorld worked perfectly with version 0.10.1.
- AnimeKai selected a `megaplay.buzz` frame and the network observer found two
  related HLS requests on the same CDN.
- Both requests had the safe replay context captured by version 0.10.1, and the

- The export contained a full transient source URL in `fallbackReason`. That is
  a privacy regression and made the 0.10.1 AnimeKai result **Needs development**.

## Version 0.10.2 changes

- Validate that HLS responses begin with `#EXTM3U`; HTML/access-control responses
  now receive an explicit `invalid-playlist` category.
- Parse `EXT-X-MEDIA:TYPE=AUDIO`, rank the requested language, and pass the
  selected audio child playlist to PyAV instead of reopening only the original
  candidate.
- Refuse a declared HLS language mismatch instead of silently transcribing a
  different dub.
- Pass FFmpeg's documented `user_agent` and `referer` protocol options
  explicitly while retaining only the existing safe custom-header allowlist.
- Reject performance/network telemetry such as JW Player `ping.gif` requests.
- Persist playlist type, audio-rendition count, declared languages, variant
  count, and selected child host without retaining playlist URLs.
- Sanitize fallback reasons before local persistence and recursively sanitize
  the pipeline again during technical export.

## Mandatory retest

1. Update the existing installation to 0.10.2 and restart the local recognizer.
2. Reload the unpacked extension and then reload the AnimeKai page.
3. Confirm the language actually playing. Use `en` for the supplied English
   AnimeKai episode unless a German stream has been selected.
4. Let the chosen player run briefly, then click **Analyze automatically**.
5. In Diagnostics, record `HTTP discovery`, `Safe request context`, and
   `HLS inspection`.
6. If batch analysis still falls back, export the new technical JSON. It must
   not contain a full CDN playlist URL or query token.

## Pass boundary

AnimeKai passes only when a full source is decoded with the intended audible
language, the transcript covers the complete video, rewind uses cached cues,
and the export remains sanitized. Discovery alone or live fallback is not a
pass.
