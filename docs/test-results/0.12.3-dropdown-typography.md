label, a half-width provider dropdown and uneven language-field alignment.

inside a two-column language grid. Popup bindings/startup tests pass at baseline;
those checks do not measure rendered typography.

plain HTML/CSS/JavaScript. Shared --ui-size-select is12px/400 weight, using the
existing bundled Open Sans family and normal tracking. Popup/player selects
and their options use it explicitly. Other controls, prose, video titles,
caption font preferences and font assets remain unchanged. Translation setup
inherits the popup styles; no separate new UI system or external requests.

their bottom edge if a heading wraps; session labels use tighter .04em tracking.
Long source/provider labels are concise while retaining all select IDs/values.
Local audio remains labelled manual-start and provider remains labelled fallback;
API-key configuration/help is retained. Native select semantics, keyboard,
contrast and control heights remain intact. No persistence/schema or service
logic changes; player controller changes are option display strings only.
