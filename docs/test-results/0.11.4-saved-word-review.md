## Changed behavior and boundaries

- Saved-word titles are keyboard-accessible native buttons in Words and recent
  words on Home. They open full details within Words, independent of a video.
- Reuses the existing card template, styles, German lookup, saved v3 dictionary
  evidence, legacy/offline fallback, direct target-language translation, strict
  highlight rule, examples, case grammar, verb overview/conjugation tables,
  German pronunciation and YouGlish. No duplicate dictionary renderer.
- Explicit extension-page review mode skips player discovery, media listeners,
  analysis and overlay diagnostic messages. It cannot activate on an ordinary
  website. Card metadata stays hidden; safe Return to source opens a new tab.
  In-video Replay stays in the player card and is unavailable in popup review.
- Back, close and Escape return to the filtered list with scroll and focus.
  Popup UI state preserves the reviewed word, detail scroll and expanded
  disclosures. Leaving Words closes the review and cancels owned speech.
- Removal works from the review or list. Storage errors remain visible; external
  removal closes the affected review. Late lookup/translation/removal responses
  cannot replace or close another card. Merely opening a saved word never writes
  dictionary/vocabulary records or changes source metadata.
- No service-worker/storage schema/acquisition changes. Existing popup state is
  extended with optional review fields; no migration or data deletion.
