# 0.11.3 compact status UI candidate

2026-10-26. WP2.4/WP2.5; baseline9fd4dd0 /0.11.2 on
codex/local-media-loopback. Plan: `docs/COMPACT_STATUS_UI_PLAN.md`.

## Changes

- Voice state is a small ready/pending/information/warning icon next to Speak.
  Hover or keyboard focus reveals the complete text. Retry remains a compact
  accessible button when needed; Escape dismisses the tooltip. No speech engine
  or voice selection changes.
- The long dictionary/provider/highlighting note is now a footer information
  icon beside the German Wiktionary link. Its full wording is preserved in the
  hover/focus description.
- Cached-replay and word-timing notices dwell for2seconds, fade for0.7seconds,
  then leave layout. Reduced motion skips the animation after the same dwell.
  Repeated frames do not reset the deadline; identical provenance does not flash
  repeatedly in a session. Current word highlights/timestamps are unchanged.
  Timing provenance remains based on available cue words between spoken words.
- Critical errors stay visible and automatic cached-replay refresh cannot
  overwrite them. Old timer callbacks cannot hide a newly displayed error.
- Four bounded session-storage fields preserve last-reported notice, timing,
  pronunciation and card-help text. Writes are serialized, experiment-scoped,
  checked against the active tab/media frame and sanitized. Popup diagnostics
  refresh on change and retain details after overlay fade or worker suspension.
  These are browser-session snapshots, not additional persistent history.
- Meanings use one display ordinal (1.,2.,3.); bracketed source references are
  omitted in the card. Source IDs and example relationships remain in dictionary
  and vocabulary data. Only leading numeric markers are removed from display;
  ordinary bracketed content inside prose is preserved.

User requested local, easy and quick checks. All completed in approximately two
seconds per combined run, without browser/media/network operations:

- `node --check` for content.js, service-worker.js and popup.js.
- `test-compact-status.mjs`: actual helpers under fake clocks;2s dwell/0.7s fade,
  frame-repeat deduplication, cleanup, reduced motion, error replacement safety,
  numbering, real worker message routing, last-reported popup details, valid
  frame/experiment checks, sanitization, bounded storage and worker restart.
- Existing targeted suites: content initialization, popup bindings, word-card
  localization, batch lifecycle and persistence safety. Six local suites total
  including the new one; all pass.
- Whitespace/source diff review passes.

No broad corpus re-evaluation, real translation/download, speech, audio capture,
transcription, browser UI or platform playback tests were run. Simulated local
passing checks do not establish real hover/fade rendering or platform acceptance.
UI candidate remains Experimental; previously recorded extraction limitations
and overall Needs development classification remain.
