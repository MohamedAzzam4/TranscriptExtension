## Why the preparation message timed out

Confirmed from code: our manager gives creation 180 seconds, then aborts and
shows a retry. The message is the extension's deadline; it is not Chrome's own
explanation. Earlier English/Arabic requests never reached creation success.
That does not prove they would never finish if allowed longer.

Chrome DevTools MCP was used for the earlier checks and this control. It is
connected and can navigate/click/evaluate. The browser is a separate
HeadlessChrome149 test environment, not the user's normal Chrome profile.

New control with the extension **uninstalled**:

1. Open Google's public Translator/Language Detector playground.
2. The demo itself reports no language-detection model available. This concerns
   a different API, so it is supporting environment evidence, not a Translator
   diagnosis by itself.
3. Add a diagnostic button calling native Translator.create directly for de→en,
   bypassing every extension helper/message/cache. Reproducible probe:
   `scripts/native-translator-probe.js` (execute on a disposable public page).
4. MCP click reports trustedClick=true and userActivation=true; API is native,
   monitor attaches and emits loaded0 then1. A100% event alone is not Ready.
5. Native creation remains unresolved at180seconds; the diagnostic aborts it.
   The resulting AbortError is ours, not an underlying native failure diagnosis.

Evidence: `raw-chrome-initialization-start/progress/result.json`. This demonstrates
the stall outside extension initialization; popup/background code cannot be its
sole cause. It does not rule out other application bugs or prove a specific
network/component/engine cause. Exact browser internals/launch flags are unknown:
MCP rejects chrome: navigation and that restriction was not bypassed. Do not
claim a particular launch flag disabled downloads, or that MCP itself disconnected.

## Useful normal-browser comparison

A short check in the user's usual Chrome is appropriate; repeating dictionary
or video tests is unnecessary. Reload the existing extension (preserve its saved
data), select German→English, open Set up translation, click Download language
resources and keep that tab in the foreground. Record Ready, exact error, or
whether progress moves before the three-minute deadline; repeat German→Arabic
afterwards. Do not start Analyze Video. If normal Chrome succeeds while this
control stalls, the automated browser environment is the practical difference.
If normal Chrome also fails, native component/download diagnostics are the next
investigation; neither result justifies guessing the underlying cause now.
