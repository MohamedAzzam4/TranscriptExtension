## Implemented behavior

- Reorganized popup around current session, translation, appearance, advanced
  timing/recognizer, diagnostics, exports, libraries, and optional research.
- Added a consistent glassmorphism visual system with readable contrast over a
  dark background.
- Added independent transcript/translation font steppers, colors, opacity,
  family, and emphasis controls.
- Added appearance reset that deliberately preserves language, provider, key,
  timing, transcript, vocabulary, and library state.
- Added accessible names, visible focus, polite caption live regions, responsive
  popup sizing, and reduced-motion handling.
- Added player-aware effective caption positioning. Manual drag stores the base
  position; visible controls temporarily raise the rendered bottom offset.
- Kept the compact English word-card sections and visible sanitized diagnostics.
- Documented event ownership and UI state invariants.

## Known limitations

- Generic players may use control-bar markup not covered by the initial
  selectors; U-11 records those cases for later adapters.
- Paused players without detectable controls use a conservative 14% lower safe
  area.
- The popup/overlay need real-browser visual inspection before Phase 2 can pass.
- This is a prototype UI refactor, not the deferred production/SaaS rewrite.
