## Earlier source changes (not retested; card sourcing subsequently revised)

The user later selected German Wiktionary only, direct German-to-target
translation, verb-only forms, strict candidate counting, pronunciation, popup
continuity, and current-word highlighting. The mixed-source/grammar portions
below describe the earlier candidate and are superseded by
[`GERMAN_ONLY_LEARNING_IMPLEMENTATION_PLAN.md`](../GERMAN_ONLY_LEARNING_IMPLEMENTATION_PLAN.md)
and its [implementation report](../GERMAN_ONLY_LEARNING_IMPLEMENTATION_REPORT.md).
The testing pause still applies; earlier automated results cannot be extended
to this subsequent implementation.

- Terra glass styling and Home/Words/Videos/Appearance navigation preserve the
  existing transcription, diagnostic, export, library, and research controls.
- Saved vocabulary can be searched/filtered and retains source sentence,
  dictionary evidence, timing, and video provenance. Exact saved source forms
  are marked across batch, live, and cached cues, including storage updates.
- The word-card heading is a direct meaning in the chosen target language,
  rather than a repetition of the selected German token. Dictionary-backed
  alternative meanings follow it.
- German definitions remain first; their exact text is translated through the
  existing provider/cache into the selected language. An English dictionary
  gloss is not presented as a translation of a different German definition.
- Explicit grammatical form references can trigger one bounded base-entry
  lookup. Base definitions are labelled. Placeholder/missing German definitions
  and English grammatical notes are not displayed as direct meanings.
- Examples are translated from German into the selected language, with `lang`
  and automatic text direction. Source words and matching target phrases are
  marked using text nodes, never provider HTML. Missing translations are shown
  as unavailable rather than silently substituted with English.
- Card localization snapshots the selected context and a request revision.
  Late responses cannot reopen a closed card, overwrite another word, or use
  the previous target language. Saving uses the clicked sentence even if the
  underlying video has advanced to another cue.
- Outside pointer actions dismiss the card without cancelling site behavior.
  Injected parent/sibling documents relay dismissal only to the active media
  frame in the same tab. Native selection and in-card actions remain owned by
  their previous handlers.
- The card has a thin green/dark scrollbar. Video titles use compact type with
  a three-line limit and full-title tooltip.
- The scaled appearance preview is sticky within the Appearance view. Text
  styling, caption background/edge, and position controls update the sample;
  sample translation follows the target language/provider when that view is
  visible. Transcript, Translation, and Caption box use bold collapsible
  summaries; only Transcript starts open.
- Vocabulary records retain optional direct meanings, explicit lemma,
  definition provenance, and grammatical notes. Old records are normalized
  without a destructive migration. Definition cache v4 leaves v3 records alone;
  the existing translation cache remains keyed by source text and language pair.

## Limits

- Saved source-word marking matches exact forms, not lemmas or inflections.
- Translated example marks are lexical matches, not forced word alignment.
  A bounded Arabic pronoun-suffix rule permits matches such as `وعد` in
  `وعدني`; unmatched paraphrases remain unmarked. These rules need browser and
  language-specific acceptance evidence.
- Alternative senses depend on dictionary availability. A word-only provider
  translation is not guaranteed to select the sentence's exact intended sense.
- The selected provider must support the requested language pair; the existing
  on-device/optional Google configuration still applies.
- Cross-frame outside dismissal requires the usual content-script injection
  into those documents; inaccessible frames remain unverified.
- Real provider behavior, upgrades, playback interactions, and current visual
  layout remain unverified. The user requested edits before further testing.
- The pre-existing native-host executable change, archives, `.opencode/`, and
  supplied design directory are outside this implementation's intended files.
