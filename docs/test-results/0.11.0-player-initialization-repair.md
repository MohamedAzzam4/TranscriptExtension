## Reproduced baseline and cause

The user supplied an AniWorld screenshot showing an existing video and a
`No accessible HTML video` error with a stale `Complete` diagnostic.
After explicitly authorizing local checks only, the user kept browser automation
and real analysis paused. `node --check extension/content.js` and the real
content-script overlay fixture both failed at line 1456 with `SyntaxError:
missing ) after argument list`. A nested per-sense example translation request
was missing a closing parenthesis. The entire content script therefore failed
to parse, including its GET_MEDIA_CONTEXT listener.

`startSmartExperiment` prepares/discovers the media target before selecting a
stored transcript. This explains why a previously saved transcript could not
be restored; no evidence of transcript deletion was found. Independently,
observer injection could count as successful inspection while application
injection failed, hiding the real initialization error behind a no-video error.
Diagnostics then read the previous completed experiment because the failed
attempt had not created a new record.

## Repairs and characterization

- Replaced the deeply nested example-translation expression with a named local
  transformation so the script parses and retains exact-form filtering.
- Required successful application injection before proceeding to media probing;
  propagate its sanitized initialization error instead of a misleading no-video
  result. An authored regression first failed with a missing expected rejection,
  then passed after the repair.
- Record preparation failure separately in extension session storage. Current
  failure diagnostics take precedence over old completed results, survive popup
  reopening, and clear at the next preparation attempt. Saved experiment and
  transcript records are not rewritten. A stale-Complete characterization first
  failed (`success` versus `error`), then passed. The fixture also invokes the
  actual failing start path and verifies preserved previous experiment state.
- Updated outdated appearance assertions to allow the existing continuity key
  attributes without weakening the first-panel-open expectation.
